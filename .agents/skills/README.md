# Project-local skills

These skills are guidance and do not install their optional toolchains.

- `gh-fix-ci` requires the GitHub CLI (`gh`) authenticated with repository and
  workflow scopes.
- `webapp-testing` requires a browser-capable test environment; its examples
  may require Playwright and its browser binaries.
- `modern-python` expects `uv`, and recommends `ruff` and `ty` for Python core
  work when that milestone begins.
- `property-based-testing` requires the property-testing library appropriate to
  the implementation language (for example Hypothesis, fast-check or proptest)
  only when a suitable invariant warrants it.

No optional tools were installed as part of skill setup.
